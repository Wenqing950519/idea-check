# Profile: geo-whitepaper

## Purpose

Research whitepapers about generative engine optimization, LLM citation selection, retrieval, ranking, structured data, and official product behavior.

## Evidence mix

- Academic mechanism or empirical effect: peer-reviewed studies and clearly labeled preprints.
- Frontier claims: recent preprints plus cross-source verification.
- Product behavior: official documentation or first-party technical sources.
- Market/vendor claims: treated as claims; require independent support for objective conclusions.

## Required workflow

Search local GEO material, run academic discovery if coverage is insufficient, acquire included full text, retrieve passages, search counterevidence and boundary conditions, then run citation audit. Separate “the source discusses structured data” from “structured data causally increases LLM citations.”

## High-risk claims

Flag causal language, universal ranking claims, unsupported novelty, product behavior inferred from third parties, metric changes without a comparable baseline, and scope shifts across engines, languages, or time periods.
